# Lensy Docs

Lensy checks whether AI tools can find, read and cite your developer documentation.

Paste the URL of any docs page. In a few seconds Lensy fetches the live page, checks it the way AI search engines and coding agents see it, and gives you a readiness score with a prioritized list of fixes.

<a class="cta" href="https://perseveranceai.com">Run a free check</a>

## What Lensy checks

| Area | What it looks at |
| --- | --- |
| **AI readiness** | Structured data, discoverability and content quality signals on the page, combined into a score out of 100. |
| **AI bot access** | Whether AI crawlers such as GPTBot and PerplexityBot are allowed to reach the page. |
| **AI citations** | Whether an AI search engine actually cites the page when asked real questions about its topic. |
| **Page check** | Whether the URL is a documentation page at all, so you don't get advice meant for a different kind of page. |

## Who it's for

- **Docs teams** who want to know how their docs show up in ChatGPT, Claude and Perplexity.
- **Developer relations** teams tracking how easily developers and their AI tools can find the product.
- **Engineers** who want a concrete fix list they can hand to a coding agent.
